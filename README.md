# Dekut Call for Help

## Introduction
Dekut Call for Help is an Android application designed to assist users in emergency situations by providing a platform to request help and manage emergency responses.

## Description
This project includes features for user account creation, emergency request handling, and administrative management. It uses Firebase for authentication and storing data, OneSignal for notifications, and various Android libraries to streamline development.

## Features
- Provide emergency requests to nearby responders.  
- Allow administrators to track, manage, and resolve incident reports.  
- Support profile images during account creation.  
- Offer real-time notifications through OneSignal.

## Requirements
- Android Studio (latest version recommended)  
- Android SDK and related tools  
- Active internet connection  

## Installation
1. **Clone the Repository:**  
   ```sh
   git clone <repository-url>
   ```
   *(Requires an active internet connection.)*

2. **Download the Application**  
   You can download the `.apk` [here](https://github.com/JohnKibocha/dekut_call_for_help/blob/master/app/outputs/apk/debug/dekut_call_for_help.apk) and then install it on your device:
   - Click the three dot icon (`⋯`) -> `Download`.
   - Install the downloaded file on your device.

3. **Open the Project:**  
   Open the folder in `Android Studio`.

4. **Sync Project:**  
   Gradle will automatically download and manage dependencies.

## Usage
1. **Connect Your Device:**  
   Use a physical device or an emulator.

2. **Run the Application:**  
   Press **Run** in `Android Studio` to build and launch the app.

3. **Create an Account:**  
   - Tap the user image to add a profile image.  
   - Fill in the required details correctly.  

4. **Admin Dashboard:**  
   - Admin credentials provide access to manage user requests and oversee incident reports.

## Additional Information
- **Internet Connection:** Required for libraries, Firebase access, and OneSignal notifications.
- **Profile Image:** Click the user icon during registration to upload a profile image.
